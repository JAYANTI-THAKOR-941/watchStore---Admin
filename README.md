# Watch Store Administration

Node.js administration project with watch and user models, administrative routes, email middleware and EJS dashboard and authentication views.

## Project structure

- `controllers/`
- `models/watchModel.js`
- `models/User.js`
- `routes/`
- `views/`
- `config/db.js`
- `server.js`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/watchStore---Admin.git
cd watchStore---Admin
```

Install Node.js dependencies with `npm install`. Configure the local database and mail service, then use the package scripts or `node server.js`. A tracked `.env` file requires private review and rotation of any real credentials; keep secrets in ignored local environment files.
